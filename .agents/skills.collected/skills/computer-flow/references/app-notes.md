# 应用特例参考

主文档只写通用方法。特定产品的版本缺陷、错误码、COM 差异放在这里，按需查阅，不要把某一台机器或某一版本的事实写进主流程。

## IM / Webhook

- 部分 IM 的 webhook 在关键词缺失或加签校验失败时返回非 0 `errcode`（例如某平台返回 `310000`）。排错顺序：先查关键词是否命中、再查加签时间戳偏差、最后查机器人是否被移出群。
- 发图通常需要图文/markdown 类型消息，直接发纯文本消息体会被忽略或报错。

## Excel 类应用

- `xlwings` 不支持 WPS。没装 Office 但装了 WPS（Windows）时，用 `win32com.client.Dispatch` 直接驱动：先试 `KET.Application`，失败回退 `ET.Application`，再失败查注册表。
- 已知部分 WPS 版本 COM 接口整体失效，遇到时回退到旧版本或改用 openpyxl 直接读写文件（放弃宏、透视表、公式重算）。
- WPS 个人版无 VBA 支持，需要宏/透视表的流程无法在 WPS 上完成。
- 写完必须 `close + save`（WPS COM 路径为 `Close(SaveChanges:=True)`），否则文件被进程锁住。
- 写完后列宽全是 `#####` 表示需要 `auto-fit-columns`；格式码用 US notation（`,` 分组、`.` 小数），Excel 会按本地化显示。

## 桌面应用自动化

- **CEF / Electron 内嵌页面**：若 UIA 只能看到 `Chrome Legacy Window` 且其下无行级节点，通常是渲染进程无障碍树未开启，而不是宿主不支持语义。此时标记 `embedded-web-no-bridge`，在交付说明里要求页面级桥接或人工接管，不要把坐标脚本标成已验收。
- **Qt / 自绘应用**：先检查完整后代节点，确认目标确实未暴露 `name/auto_id/role/value/action` 后才降级到 OCR。抽屉、滑出面板常是独立顶层窗口（`GW_OWNER` 指向主窗口），不在主窗口截图里。
- **多显示器**：窗口可能位于负坐标（副屏在主屏上方或左侧）。`GetWindowRect` 返回 `-32000` 附近说明窗口最小化，不是真实位置。

## IM 桌面端（某应用）

一个真实固化流程（模块入口 → 审批类应用 → 历史记录 → 区间筛选 → 详情抽屉 → 下载 PDF → 另存为）里实测到的行为。绑定该版本，产品更新后先按本文档复验。

- **日期区间筛选**：点复合日期控件的中间会聚焦容器，后续键入被丢弃——要点日期文本本身。键入后必须 `Enter` 提交，否则下一次焦点变化会静默回退成旧值。已填值上按 `Escape` 只关弹层，值不清，不能用来「清空」。
- **「重置」只清输入，不刷列表**：重置后表格仍显示上一次查询的结果，必须再点一次查询才回到初始列表。漏掉这一步，下一行会从陈旧列表开始，打开的是别的记录。
- **小窗口下入口不在首屏**：逻辑画布被压到 960×516 时，内容区只渲染首屏的几个入口，导航目标根本不在当前视口。定位器原地重试永远失败，要滚动导航栏右侧的内容区（上下都试），滚完重新抓图再识别，不要在旧截图上重复匹配。
- **详情抽屉是独立顶层窗口**：点击前记录窗口句柄集合，点击后按 `GW_OWNER` 链做差集等新句柄出现。抽屉滑入动画期间截图读到的是空面板，等窗口几何稳定后再读。关闭按钮位置随面板宽度变，固定内缩会点偏，按 × 字形定位。
- **抽屉头部图标无文本**：下载、分享、打印等图标 OCR 全部为空。以「含编号的文字行」为锚点，在该行右侧做像素列投影找 blob，该版本顺序固定为分享、下载、打印、新建、更多，取第二个即下载。整头扫描会先命中标题栏的控制按钮——blob 签名和图标一样，但功能完全不同。
- **系统「另存为」对话框**：`#32770` 顶层窗口。往文件名 `Edit` 直接 `set_edit_text` 完整绝对路径，一步设定目录和文件名，比逐级导航稳——对话框会记住上次目录，导航路径会漂。
- **覆盖确认是兄弟弹窗**：文件已存在时弹出的是另一个 `#32770`，不是复用原对话框；按钮没有 automation id，只能按标签匹配，且标签里可能夹零宽字符（`U+200B`），匹配前剥掉。
- **结果列表刷新有延迟**：查询后立刻找「查看」会得到空列表，等行出现或结果数量稳定再动。选行按编号匹配同一行，不能按下标——应用的行序和输入顺序无关。
- **抽屉内容必须断言**：打开后用编号核对抽屉内容（UIA 文本 → 头部小区域 OCR，两级降级）。点得太快会打开上一条记录，产出两个内容相同的文件，这是这类流程里最贵的静默错误。
- **复用已运行实例**：应用已在运行时接管现有窗口，不要启动第二个实例。窗口句柄随重启变化，坐标缓存要以「窗口几何 + 缩放」为键，窗口一换全部失效。
- **自绘输入框**：输入框没有 UIA `Edit` 节点，点击落点在标签右侧的固定偏移处。填完要 OCR 回读确认值真的出现在字段里，再点查询——未提交的文本会被查询忽略，表现像「筛选不生效」。
- **同一文案多处命中**：入口名会同时出现在导航、页面标题、面包屑，实测同一文案 OCR 命中 8 个候选。只按文本点会点错位置，用区域限定或近邻锚点消歧。
- **DPI 虚拟化**：实测该应用被系统虚拟化时逻辑画布只有 960×516，控件压到十几像素。处理办法是给 exe 加 DPI 兼容性标记再重启应用（本机实际执行过，原注册表值不存在，恢复=删除该值）；是否生效看 `GetDpiForWindow` 与逻辑尺寸是否变化，不看观感。改注册表前先备份原值并取得使用者同意。
