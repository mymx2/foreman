# 修复与制图工法

来源：skill.sh 社区十家技能蒸馏（flue/photoshop、photoshop-automator、dcc-mcp-photoshop 全家、still-image-retouching-finishing、photo-restoration、rescue-bad-photo、krita、gimp、photoshop-cutout、image-editing），个别条目为通用工法补充、以（通用）标注。只留与宿主无关的工法；命令映射以 `engine.commands` 实测为准。

## 固定顺序

- 修复稿（老照片/损伤稿）：先修结构（去尘、划痕、撕痕、扫描边框）→ 恢复对比度与色调 → 最后才是上色和增强。上色绝不在修复前。
- 调整一律全局→局部：方向/裁剪 → 白平衡 → 曝光与黑白点 → 色调曲线 → 全局色 → 局部蒙版 → 修补 → 输出锐化。忌倒置。
- 去噪在最终锐化之前；只锐化重要边缘，不对色度噪声和压缩块锐化；提过阴影后补一次降噪。
- 每步只改一件事；复杂编辑拆多轮，忌一次改完。

## 动手前：诊断与锚定

- 先出诊断清单（曝光/色偏/细节/构图/损伤分项），并写下真相边界：可修什么、禁改什么。
- 硬锚（禁动）：人脸身份、解剖结构、文字、logo、产品设计、地标。软锚（可动）：光照、裁剪、背景杂物、非关键色。
- 修补/去物只在软锚区域动手；硬锚确需改动，先出方案让用户定。缺失区域的重建、考证不了的上色，交付时声明"推断补全"。

## 非破坏工法

- 烘焙类滤镜（blur/sharpen/distort 等）优先走非破坏流：`filter.convertForSmartFilters`，或先 `layer.smartObjects.convertToSmartObject` 再滤镜，参数可回改；做不到就复制图层在副本上做，副本即退路。
- 非破坏锐化：高通滤镜出细节层 + 叠加/线性光混合，替代直接 sharpen 烘焙（通用工法）。
- 选区顺序：expand/contract 改几何在前，feather 放最后；危险编辑前把选区存成通道/蒙版。
- 文字层改动走稀疏参数（只传要改的字段），改前按 ID 确认是文字层，改后 inspect 读回；缺字体=未完成。
- 可重跑：每轮新落版本化文件（`_v2`），不在旧版本文件上续改。

## 抠图与合成

- 抠图流程：取选区 → 反选 → 选区转蒙版；不擦像素，蒙版是交付形态。羽化按边缘类型和输出尺寸调（约 2px 只是通用起点）；切图、去白边与导出见 `references/cutout-slicing.md`。
- 合成目标用空间方位描述（"左上角的桌子"），并明说哪些区域保持不变。
- 光影一致性：先定视线落点与阴影深度，禁全局平坦提亮把所有区域等亮；肤色不得偏灰/橙/品红/绿。
- 混合光色偏先校主体白平衡，背景可留轻微冷暖。
- 裁剪是必选动作：至少比较 3-4 种构图（原比例修正/主体放大/表达性画幅/负空间），保留原构图给理由；禁切关节、指尖、文字、产品轮廓。

## 人像与上色

- 只修临时瑕疵（红眼、油光、短期斑点）；保留毛孔、细纹、不对称、疤痣。优先 dodge/burn 与色调均匀，禁大面积磨皮。
- 上色克制：低到中饱和；肤色多区变化不做单色平涂；白、黑、金属、石材、纸张等不上色（除非场景需要）。
- 默认保留颗粒与年代痕迹，除非用户明确要"现代翻新"。

## 验收

- 双尺度：fit-to-screen 看构图与色彩，100% 看修补伪影（重复克隆纹理、halo、蜡皮、死黑、剪白、条带）。
- 关键改动做效果探针：改动层隐藏前后渲染对比像素差（headless `doc.render` + `scripts/psd-compare.py` 可当探针；GUI 会话先 `app.save` checkpoint 再转 headless）；属性回显不算数。探针若改了状态要复原，复原不了要报出来。
- 验证三态：有效 / 无效 / 测不到；"测不到"单列，不当通过。
- 抠图量化验收：透明占比、主体占比、alpha 通道存在性 → PASS/REVIEW；REVIEW 不得声称"背景已去除"。边缘另在浅色、深色、棋盘格三种背景 100% 检查白边/halo。
- 批量修复逐张出结果清单（no_op / inconclusive / unrestored），静默跳过是最危险的失败模式。

## 导出与交付

- resize_canvas（改画布不重采样）与 resize_image（重采样）分开用；缩放保宽高比。
- flatten/merge 只在交付最后一步、在副本上做；分层母版（PSD/PSB/.pcraft）先落盘。
- 双件交付：平图（PNG/JPEG）+ 可编辑母版，除非用户明确只要其一。
- 单层导出铺回整幅画布保对齐；按索引选层不按名字（名字会重复或被改写）；文件名消毒非法字符。切图/多倍率/命名/去白边另见 `references/cutout-slicing.md`。
