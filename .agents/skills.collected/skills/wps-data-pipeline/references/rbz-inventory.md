# 在库表结构（本仓专用）

标签只有四类，写成 `来源·结论`：

| 标签 | 含义 | 引用前必须确认 |
|---|---|---|
| `实测·可用` | 本机跑通过或已复现可用 | 能指向可执行复验命令，或指向本文件带复验命令的表行 |
| `实测·不可用` | 本机复现过失败 | 同上；拿不出复验方式的降级为 `推断` |
| `文档·未测` | 官方文档或上游参考实现里有，本机未跑 | 注明文档/代码位置；改关键路径前先小范围试一次 |
| `推断` | 无文档依据，靠机制推理 | 不得作为交付依据 |

「实测」不是修辞：凡出现处都要能指向一条可执行复验命令；**脚本未暴露入口的 action 例外**，须在该行注明「脚本无入口」。

本文件只对「在库表-2021.07.06至今」这一个工作簿有效，随项目归档；把本技能移植到别处时**整份删除**。

本仓专有的东西只允许写在这里：工作簿名、具体表名、逐表行列数、逐表分项计数、逐表复算命令。通用参考（`cloud-channel.md` / `local-com.md` / `data-pitfalls.md`）不写表名和逐表条数，需要时指向本文件——本文件是这些名称与数字的唯一落点，删掉它，别处的引用一起失效，不留孤证；移植时把别处出现的「在库表」一并替换为 `<你的工作簿名>`。

取数通道与解析口径见主文件与 `data-pitfalls.md`，这里只记结构与字段语义，外加本仓的数字。

## 分表复算（判断口径有没有跑偏）

拿同一份文件跑，命中数应落在下面的量级（命令在**用户工作目录**执行，脚本用绝对路径 `"$SKILL/scripts/parse_workbook.py"`，`$SKILL` 指技能安装目录）。数据会随快照变，但**量级和比例不该跳变**；差一个数量级说明表头行选错或列名对不上，不要继续往下算。

```bash
python "$SKILL/scripts/parse_workbook.py" 导出.xlsx --sheet A       --where "出库时间=空"   # 期望 ≈ 313
python "$SKILL/scripts/parse_workbook.py" 导出.xlsx --sheet B       --where "出库时间=空"   # 期望 ≈ 181
python "$SKILL/scripts/parse_workbook.py" 导出.xlsx --sheet 数字至F  --where "出库时间=空"   # 期望 ≈ 11,860
python "$SKILL/scripts/parse_workbook.py" 导出.xlsx --sheet G       --where "出库时间=空"   # 期望 ≈ 2,385
python "$SKILL/scripts/parse_workbook.py" 导出.xlsx --sheet XYZ     --where "出库时间=空"   # 期望 ≈ 2,187
```

`--where` 的语义：`=` 归一化后相等、`!=` 不等、`~` 子串包含、`^` 前缀，值是 `空` / `(空)` / 空串时匹配空值；多个 `--where` 是「与」。表名带括号或空格时给 `--sheet` 加引号。

## 核心字段（以 A 表为例）

| 字段 | 含义 | 注意 |
|---|---|---|
| 在播渠道 | 当前销售渠道 | 大量为空或 `.`；`.` 不是有效渠道值 |
| 出库时间 | 出库日期 | 混合类型，见下 |
| 库存状态 | 在库 / 已出库 / 退库 | 「退库」也带出库时间，统计时要分开算 |
| 库位号 | 物理库位 | 混入「杂」「杂框」「1手卷」等形制描述 |
| 入库编号 | 内部编号 | 形如 `a2202`，前缀区分批次 |
| 姓名 / 作品名称 / 类型 | 艺术家与作品 | 类型如 书法 / 山水 / 花鸟 / 油画 |
| 高 / 宽 / 张数 / 平尺 | 尺寸与计量 | 数值型，单位未在表内标注 |
| 建议售价 / 底价 | 定价 | 多为空，成交数据不在此表 |

## 出库时间的四种形态

| 形态 | 量级 / 依据 | 处理 |
|---|---|---|
| `datetime.date` | 约 17.6 万（`推断`，只作量级） | 直接用 |
| 8 位整数/浮点，如 `20211216.0` | 合计 7,087（分表见上「逐表分项计数」） | 按 `YYYYMMDD` 解析 |
| 文本标记，如 `特惠` `禁售` | 各表零星数十条，未逐表计数 | **保留**，不是脏数据，是业务状态 |
| 空 | 合计 16,926（分表见上「逐表分项计数」） | 不计作 0，单独统计 |

只有空值那一行有逐表复算命令（`实测·可用`）；8 位整数/浮点那 7,087 与文本标记两类没有复算命令——`--where` 只比归一化后的值，无法按形态筛——降为 `推断`；日期形态那 17.6 万是约数，同样 `推断`。

这四行**不是互斥分区，不能相加，也不能拿总行数当分母**：「待拍作品登记」5,939 行与「字典」15,075 行没有「出库时间」列，扣掉表头后有该列的数据行最多 `212,409 − 5,938 − 15,074 = 191,397`（212,409 = 212,422 总行数减 13 行表头）。三个已统计桶相加是 `176,000 + 7,087 + 16,926 = 200,013`，比上限多 8,616。差额说明三个桶不是同一口径下的互斥分区：176,000 若按全簿日期格计、空值只按五张表计，两者分母不同；多出的 8,616 无法用覆盖不全解释，待按同一口径重算后再引用。原先的占比结论已从 `data-pitfalls.md` 与本文删除。

空值行的作品实际可能已出库（时间没填），所以「按时间统计」天然漏计。报数时必须给出空值条数作为分母说明。

## 统计口径约定

1. **「今天出库」** = `出库时间 = 当天` 且 `库存状态 = 已出库`；`退库` 单列，不混入。
2. 跨表汇总按**列名**映射，不按列序号（各表列序不同）。
3. 库位维度统计只用白名单命中的行，形制描述行单列，分母透明。
4. 同一艺术家多件作品时，件数与人数分开报。
