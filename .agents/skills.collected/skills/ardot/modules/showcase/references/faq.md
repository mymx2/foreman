# FAQ / 常见问题

## Q1：需要提前学很多规则才能用吗？

不需要。在 Ardot 里选中画板，说「把选中的画板排成展示区」即可触发。只有分组有歧义时才会反问一次。

## Q2：技能没有触发或什么都没做？

确认三件事：

1. Ardot 已打开目标文件。
2. 已选中要排版的画板或 page，或已提供 nodeId。
3. Ardot MCP 连接正常。

确认后重新触发。

## Q3：生成内容覆盖已有画板怎么办？

正常流程必须先调用 `locate_available_space` 找空位，`padding` 不低于 400。如果仍覆盖，通常是调用失败后误用了手写坐标。立即停止交付，删除/移走异常展示区，重新走寻位流程。

## Q4：生成后 Ardot 里看不到新内容？

MCP 写入成功后 Ardot 视图有时不自动刷新。在 Ardot 中按 `Cmd+R` 或点击画布空白处触发重新渲染。

## Q5：标题歪掉、和内容不对齐？

使用最新版并套用 `references/skeleton-spec.md` 的「对齐硬契约」：titlebar、title row、subtitle、group label、cell row 必须共享同一左基准线。复验 `absoluteBoundingBox.x`，容差 ±1px。

## Q6：想用白底或灰底怎么说？

直接说「白底」「浅色」「灰底」「护眼」「演示模式」。技能根据 `$themeAliases` 自动切换 preset，并同步切换文字颜色，保证可读性。

## Q7：分组结果不对怎么办？

重新触发，在 Step 1.5 选择「自定义」，直接描述正确分组。若已生成，应重新生成展示区，不要手动微调错误结构。

## Q8：可以只修改已有展示区的某个 cell 吗？

本技能不精修 cell 内部。修改源画板即可；展示区中的 cell 优先通过 `ref` 引用源画板，源画板更新后展示区同步。

## Q9：为什么同一链路不加分隔线？

同一链路的多状态需要视觉连续，例如默认态 / 输入态 / 校验失败 / 成功。column divider 只用于同一 group 内不同能力或模块之间的边界。

## Q10：为什么有时要先问分组？

轴向只能解决「怎么排」，不能解决「谁和谁一组」。当原始画布存在多种合理分组解释时，必须先让用户确认，避免把用户已有结构打散。
